# MisterBeat

This is a React-based music station management app built during a short course project. It interacts with a backend API.

## Setup

1. Copy `.env.example` to `.env` and edit the API URL if needed.
2. Install dependencies: `npm install`.
3. Run the development server: `npm start`.

The frontend expects a backend server that exposes the API under the URL specified in `REACT_APP_BASE_API_URL`.
